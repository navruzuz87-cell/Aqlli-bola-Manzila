# ManZila: Aqlli Bola — yagona asosiy loyiha arxivi

Ushbu arxiv Phase 11 (profil va navigatsiya) holatidagi to'liq Flutter manba loyihasini hamda loyiha hujjatlarini bir joyga jamlaydi.

## Tarkibi
- `lib/` — Flutter/Dart ilova manba kodi
- `assets/` — tasvirlar, robot-mascot va audio resurslar
- `test/` — mavjud avtomatik testlar
- `docs/` — Phase 2–11 texnik hujjatlari, handoff va changeloglar
- `docs/reference/` — dastlabki PRD va dizayn/qarorlar PDF hujjati
- `pubspec.yaml` — Flutter paketlari va aktivlar konfiguratsiyasi

## Joriy versiya
- Bazaviy holat: v56, Phase 11
- Oxirgi birlashtirilgan modul: profil va navigatsiya
- Bu arxiv Android APK tayyor degani emas. Flutter SDK mavjud muhitda `flutter pub get`, `flutter analyze`, `flutter test` va Android build bajarilishi shart.

## Keyingi ish tartibi
Keyingi barcha o'zgarishlar shu loyiha ustida davom ettiriladi. Muhim relizlarda ushbu yagona master ZIP yangilanadi; alohida kichik ZIPlar chiqarilmaydi.
